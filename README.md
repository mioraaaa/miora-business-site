# MIORA Customer Website — Starter

This is the first static customer-facing design foundation for MIORA. The exact user-supplied original logo is stored unchanged at `assets/miora-original-logo.jpg`.

## Current status
- Premium responsive MIORA-branded landing page
- Product category navigation based on the supplied brand banner
- Catalogue placeholder (no fabricated product inventory or prices)
- PWA manifest and basic offline shell caching
- No paid libraries or AI services required

## Not yet implemented
Customer authentication, database, product CRUD, party-specific discounts, cart/order persistence, estimate PDF generation, payment verification, WhatsApp API, admin panel, and visual page builder. These require connected GitHub repository and configured Cloudflare resources plus verified company/product data.

## Preview
Serve this folder with any static HTTP server. For PWA behavior, use HTTPS or localhost.
